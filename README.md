# Kindness Classes

Kindness Classes is a simple static website focused on promoting kindness, empathy, and ethical values through educational content and community initiatives.

The project was developed and maintained by **Apex Poudel**, a student at Motherland School.

## 🌱 About the Project

Kindness Classes aims to:
- Encourage empathy and kindness among students
- Provide accessible educational content
- Support social good initiatives through awareness and donations

This website is intentionally lightweight and fast, built as a static site for reliability and ease of access.

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- Hosted on Netlify
